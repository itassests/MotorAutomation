Standard Operating Procedure

Bulk OCR Upload

RateExtract Portal  ·  OneInsure Motor Automation

1. What this screen does

The Bulk OCR Upload screen lets you upload ZIP folders of policy PDF copies in bulk. For every PDF, the system automatically:

  • Generates a Tracker Number for the policy,
  • Runs OCR on the PDF to read the Policy Number, and
  • Records the Tracker Number against the Policy Number so it can be exported.

Processing runs in the background on the server — you can start an upload and leave the screen, and your work is not lost.

2. Who can use it

This screen is restricted to a single authorised operator (employee code 107110). It is not visible to other users, including administrators. If you cannot see the OCR Bulk Upload tab, you are not logged in with the authorised employee code.

3. Before you start — prepare your files

  • Put the policy PDF copies into a .zip file. One ZIP can hold many PDFs, and they may be inside sub-folders — the system finds all PDFs automatically.
  • Each PDF should be a single policy document (the policy copy that shows the policy number).
  • Only .pdf files are processed. Other file types in the ZIP are ignored.
  • You can select and upload several ZIP files at once.
  • Give the ZIP a meaningful name (for example, location-poscode-insurer-period) so it is easy to find later in the folder list.

4. Logging in

  1. Open the RateExtract portal in your browser.
  2. Enter your employee code (107110) and continue.
  3. Enter the OTP provided to you and sign in.
  4. Click the OCR Bulk Upload tab (box icon) in the left menu.

7. Monitoring progress

  • The folder list auto-refreshes every 3 minutes while the tab is open, so finished folders update on their own.
  • Each in-progress folder's Progress cell updates every few seconds.
  • Use the Refresh button or the Pending / Done / All filter to look at a specific set of folders.
  • You may safely leave the screen and return later — processing continues on the server.
About “Process now”: processing normally runs automatically in the background. The Process now button triggers one extra processing pass and is only needed if support asks. Pressing it does not harm anything.

8. Downloading the results

  1. Find the folder in the list (use the Done only filter to see completed ones).
  2. Click the Excel button on that row.
  3. An Excel file downloads with two columns: Policy No and Tracker No.

9. Handling failed PDFs

If a folder's Progress shows a red N failed link, click it to see which PDFs could not be read and why. Common reasons:

  • The PDF is a scanned image of poor quality, or is not actually a policy copy.
  • The PDF is password-protected or corrupted.

Re-check those documents and, if needed, re-upload corrected copies in a new ZIP. Share the failure details with support if the cause is unclear.
